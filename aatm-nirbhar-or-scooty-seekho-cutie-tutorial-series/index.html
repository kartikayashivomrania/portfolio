Scooty Seekho Cutie

Project Overview

Scooty Seekho Cutie is a scooter-learning tutorial series created for Aatm Nirbhar. Designed to make learning to ride a scooty more approachable, the series uses accessible, practical tutorial-style content to help women build confidence and learn a new skill.
